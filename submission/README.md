# submission/

Final submission package. For each submission create a subfolder named `<Class> - <Title without accents> - <Full name>` containing:

- `Report.pdf`, `Slides.pdf`
- `Drawings/` (drawings, schematics)
- `Pictures/`, `Video Clip/`, `References/`
- `CHECKLIST_MISSING.txt` (template below)

## CHECKLIST_MISSING.txt template

```
SUBMISSION PACKAGE CHECKLIST
Included:
[x] Report PDF
Still missing:
[ ] Slides (.pptx)
[ ] Real-hardware video
[ ] Signed forms
```
